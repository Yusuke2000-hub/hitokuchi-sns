## 機能概要

テキスト（280 文字制限）と画像（1 枚）を投稿できる。自分の投稿のみ編集・削除が可能。画像は AWS S3 にアップロードして保存する。

---

## 機能要件とユースケース

### 1. 投稿作成（F-06）

- ログインユーザーがテキストを入力し投稿する
- テキストは 1 文字以上 280 文字以内
- 画像は任意（1 枚まで）。選択した画像はプレビュー表示する
- 投稿ボタン押下時に画像を S3 にアップロードし、URL を posts テーブルに保存する
- 投稿成功後はタイムライン画面に遷移（または投稿をその場で追加して更新）

**フロー**

```
ユーザー → 投稿作成画面でテキスト入力・画像選択
         → POST /api/posts（multipart/form-data）
         → バリデーション（文字数・画像形式・サイズ）
         → 画像がある場合は S3 にアップロードし URL を取得
         → posts テーブルに保存
         → レスポンス（作成した投稿データ）
         → タイムライン画面へ遷移
```

### 2. 投稿編集（F-07）

- 自分の投稿のみ編集できる
- テキスト・画像を変更できる
- 画像を削除して「テキストのみ投稿」に変更することもできる
- 編集後は投稿詳細画面またはタイムラインに戻る

### 3. 投稿削除（F-08）

- 自分の投稿のみ削除できる
- 削除は物理削除とする
- 削除確認ダイアログを表示してから実行する
- 削除後はタイムライン画面へ遷移する

---

## バリエーション

| バリエーション | 内容 |
|---|---|
| テキストのみ投稿 | 画像なし。image_url は NULL |
| テキスト＋画像投稿 | 画像を S3 にアップロードし、URL を保存 |
| 編集で画像を削除 | S3 から旧画像を削除し、image_url を NULL に更新 |
| 編集で画像を差し替え | S3 から旧画像を削除し、新画像をアップロードして URL を更新 |

---

## エラーケース

| ケース | 発生条件 | ユーザーへの表示 |
|---|---|---|
| テキスト未入力 | テキストが空白のみ | 「投稿内容を入力してください」 |
| 文字数超過 | テキストが 281 文字以上 | 「280 文字以内で入力してください（現在 {n} 文字）」 |
| 画像形式不正 | JPEG・PNG・GIF・WebP 以外のファイル | 「対応している画像形式は JPEG・PNG・GIF・WebP です」 |
| 画像サイズ超過 | ファイルサイズが 5MB を超える | 「画像は 5MB 以下にしてください」 |
| 他ユーザーの投稿の編集・削除 | 投稿の user_id がログインユーザーと不一致 | HTTP 403 エラー（フロントエンドでは操作ボタン自体を非表示） |
| S3 アップロード失敗 | ネットワーク障害など | 「画像のアップロードに失敗しました。再度お試しください」 |
