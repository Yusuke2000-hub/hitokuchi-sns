## 機能概要

メールアドレスとパスワードによる新規登録・ログイン・ログアウト。認証には JWT（JSON Web Token）を使用し、フロントエンドのローカルストレージに保存する。以降の API リクエストは Authorization ヘッダーに Bearer トークンを付与して送信する。

---

## 機能要件とユースケース

### 1. 新規登録（F-01）

- メールアドレス・パスワード・ユーザー名を入力して登録する
- パスワードは bcrypt でハッシュ化して保存する
- 登録成功時に JWT を発行し、タイムライン画面へ遷移する
- email と username はそれぞれ UNIQUE 制約を持つ

**フロー**

```
ユーザー → 新規登録画面でフォーム入力
         → POST /api/auth/register
         → バリデーション（必須チェック・フォーマット・重複チェック）
         → パスワードを bcrypt でハッシュ化
         → users テーブルに保存
         → JWT 発行・レスポンス
         → フロントエンドがトークンをローカルストレージに保存
         → タイムライン画面（/）へ遷移
```

### 2. ログイン（F-02）

- メールアドレスとパスワードを入力してログインする
- パスワードが一致すれば JWT を発行する
- ログイン成功後はタイムライン画面へ遷移する

**フロー**

```
ユーザー → ログイン画面でフォーム入力
         → POST /api/auth/login
         → メールアドレスでユーザーを検索
         → bcrypt でパスワード照合
         → JWT 発行・レスポンス
         → フロントエンドがトークンをローカルストレージに保存
         → タイムライン画面（/）へ遷移
```

### 3. ログアウト（F-03）

- フロントエンドでローカルストレージの JWT を削除する
- バックエンドへの API リクエストは不要（ステートレス）
- ログアウト後はログイン画面へ遷移する

---

## バリエーション

| バリエーション | 内容 |
|---|---|
| パスワードリセット | スコープ外（本バージョンでは実装しない） |
| SNS ログイン | スコープ外（OAuth は本バージョンでは実装しない） |
| メール確認 | スコープ外（登録後の確認メール送信は行わない） |

---

## エラーケース

| ケース | 発生条件 | ユーザーへの表示 |
|---|---|---|
| メールアドレス重複 | 登録済みのメールアドレスで新規登録 | 「このメールアドレスはすでに登録されています」 |
| ユーザー名重複 | 登録済みのユーザー名で新規登録 | 「このユーザー名はすでに使用されています」 |
| メール形式不正 | 正規表現に一致しないメールアドレス | 「メールアドレスの形式が正しくありません」 |
| パスワード要件未達 | 8 文字未満などの要件を満たさないパスワード | 「パスワードは 8 文字以上で入力してください」 |
| 必須項目未入力 | いずれかのフィールドが空 | 「{フィールド名}は必須です」 |
| 認証失敗 | メールアドレスまたはパスワードが一致しない | 「メールアドレスまたはパスワードが正しくありません」 |
| トークン期限切れ | JWT の有効期限が切れた状態でリクエスト | 自動的にログイン画面へリダイレクト |
