## 機能概要

タイムライン画面では「全体」と「フォロー中」の 2 種類をタブで切り替えて表示する。各投稿にはユーザー名・テキスト・画像（あれば）・いいね数・コメント数を表示する。ユーザー名クリックでプロフィール画面へ遷移できる。

---

## 機能要件とユースケース

### 1. 全体タイムライン（F-04）

- 全ユーザーの投稿を作成日時の降順で表示する
- ログイン不要でも閲覧できる
- 各投稿カードに以下を表示する：
  - ユーザーのアイコン
  - ユーザー名（クリックでプロフィール `/users/:username` へ遷移）
  - 投稿テキスト
  - 投稿画像（添付がある場合のみ）
  - いいね数・コメント数
  - 投稿日時

### 2. フォロー中タイムライン（F-05）

- ログイン中のユーザーがフォローしているユーザーの投稿のみ表示する
- 表示形式は全体タイムラインと同じ
- ログインが必要（未ログイン時はログイン画面へリダイレクト）

### 3. ページ送り

- 「もっと見る」ボタン方式（オフセットベース）で実装する
- 1 ページあたりの表示件数は 20 件

---

## バリエーション

| バリエーション | 内容 |
|---|---|
| フォロー中ユーザーが 0 人 | 「フォロー中のユーザーがいません。ユーザーを検索してフォローしてみましょう」と表示 |
| 投稿が 0 件 | 「まだ投稿がありません」と表示 |
| 画像なし投稿 | 画像エリアを非表示にし、テキストのみ表示 |
| 自分の投稿 | 編集・削除メニューを表示する（他ユーザーの投稿には表示しない） |

---

## エラーケース

| ケース | 発生条件 | ユーザーへの表示 |
|---|---|---|
| API エラー | サーバーエラーや通信障害 | 「投稿の取得に失敗しました。再度お試しください」 |
| 未ログインでフォロー中タイムラインにアクセス | 認証トークンがない | ログイン画面へリダイレクト |
