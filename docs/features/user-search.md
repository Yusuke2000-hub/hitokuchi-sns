## 機能概要

ユーザー名で他のユーザーを検索できる。検索結果または投稿・コメント上のユーザー名クリックでプロフィール画面へ遷移できる。

---

## 機能要件とユースケース

### 1. ユーザー検索（F-14）

- 検索画面（`/search`）でテキストを入力してユーザーを検索する
- ユーザー名の部分一致で検索する（大文字・小文字を区別しない）
- 検索結果には以下を表示する：
  - ユーザーのアイコン
  - ユーザー名
  - 自己紹介テキスト（先頭 50 文字程度）
- 検索結果のユーザーをクリックするとプロフィール画面（`/users/:username`）へ遷移する

### 2. ユーザー名クリックによるプロフィール遷移

- タイムラインの投稿カードのユーザー名をクリックすると、そのユーザーのプロフィール画面へ遷移する
- 投稿詳細画面のコメント一覧のユーザー名をクリックしても同様に遷移する

---

## バリエーション

| バリエーション | 内容 |
|---|---|
| 検索結果 0 件 | 「"{キーワード}" に一致するユーザーは見つかりませんでした」と表示 |
| 検索テキスト未入力 | 検索ボタンを非活性にする（または入力中に随時検索） |
| 自分自身が検索結果に含まれる | 通常通り表示する（フォローボタンは非表示） |

---

## エラーケース

| ケース | 発生条件 | ユーザーへの表示 |
|---|---|---|
| API エラー | サーバーエラーや通信障害 | 「ユーザーの検索に失敗しました。再度お試しください」 |
| 空白のみの入力 | スペースのみを入力して検索 | 「検索キーワードを入力してください」 |
