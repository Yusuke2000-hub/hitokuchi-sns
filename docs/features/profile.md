## 機能概要

ユーザーのプロフィール（ユーザー名・アイコン・自己紹介）を表示・編集できる。フォロー／フォロワー機能を持ち、フォロー中・フォロワー数を表示する。

---

## 機能要件とユースケース

### 1. プロフィール表示（F-11）

プロフィール画面（`/users/:username`）に以下を表示する：

- ユーザーのアイコン画像
- ユーザー名
- 自己紹介テキスト
- 投稿数
- フォロー中の数（クリックでフォロー中一覧へ）
- フォロワーの数（クリックでフォロワー一覧へ）
- そのユーザーの投稿一覧（新着順）
- ログインユーザーが自分のプロフィールを見る場合：プロフィール編集ボタンを表示
- ログインユーザーが他ユーザーのプロフィールを見る場合：フォロー／フォロー解除ボタンを表示

### 2. プロフィール編集（F-12）

- 自分のプロフィールのみ編集できる
- 変更可能な項目：ユーザー名、アイコン画像（S3 にアップロード）、自己紹介テキスト
- ユーザー名は UNIQUE 制約があるため重複チェックが必要

### 3. フォロー（F-13）

- 他のユーザーのプロフィール画面からフォローできる
- フォロー後はボタンを「フォロー中」状態に切り替える
- 自分自身はフォローできない

### 4. フォロー解除

- フォロー中のユーザーのプロフィール画面からフォロー解除できる
- フォロー解除後はボタンを「フォロー」状態に戻す

### 5. フォロー中一覧・フォロワー一覧

- フォロー数・フォロワー数のクリックで専用画面へ遷移する
  - フォロー中一覧：`/users/:username/following`
  - フォロワー一覧：`/users/:username/followers`
- 一覧にはアイコン・ユーザー名を表示し、クリックでプロフィールへ遷移できる

## バリエーション

| バリエーション | 内容 |
|---|---|
| 自分のプロフィール | フォローボタン非表示、プロフィール編集ボタン表示 |
| 他ユーザーのプロフィール（未フォロー） | 「フォロー」ボタン表示 |
| 他ユーザーのプロフィール（フォロー中） | 「フォロー中」ボタン表示 |
| アイコン未設定 | デフォルトアイコン（プレースホルダー画像）を表示 |
| 自己紹介未設定 | 自己紹介エリアを非表示または空白表示 |

---

## エラーケース

| ケース | 発生条件 | ユーザーへの表示 |
|---|---|---|
| 存在しないユーザーのプロフィール | URL のユーザー名が存在しない | 「ユーザーが見つかりません」（404 相当） |
| ユーザー名重複（編集時） | 他ユーザーがすでに使用しているユーザー名に変更 | 「このユーザー名はすでに使用されています」 |
| 画像形式不正 | JPEG・PNG・GIF・WebP 以外のファイルをアイコンに設定 | 「対応している画像形式は JPEG・PNG・GIF・WebP です」 |
| 画像サイズ超過 | アイコン画像が 2MB を超える | 「アイコン画像は 2MB 以下にしてください」 |
| 自分自身をフォロー | フォローリクエストの follower_id と following_id が同一 | HTTP 400 エラー（フロントエンドでボタン自体を非表示） |
| 未ログインでプロフィール編集・フォロー | 認証トークンがない | ログイン画面へリダイレクト |
