## 機能概要

投稿に対してコメントを追加できる。コメント一覧では投稿者のユーザー名とテキストを表示する。タイムラインおよび投稿詳細画面でコメント数を表示する。

---

## 機能要件とユースケース

### 1. コメント作成（F-09）

- ログインユーザーが投稿詳細画面でコメントを入力して送信する
- コメントテキストは 1 文字以上 280 文字以内
- 送信後、コメント一覧に追加表示する（ページリロードなし）

### 2. コメント削除

- 自分のコメントのみ削除できる
- 削除確認ダイアログを表示してから実行する
- 削除後はコメント一覧から当該コメントを除去する

### 3. コメント一覧表示

- 投稿詳細画面でコメント一覧を表示する
- 各コメントに以下を表示する：
  - 投稿者のアイコン
  - 投稿者のユーザー名（クリックでプロフィール `/users/:username` へ遷移）
  - コメントテキスト
  - 投稿日時
  - 自分のコメントには削除ボタンを表示

### 4. コメント数表示

- タイムラインの各投稿カードにコメント数を表示する
- 投稿詳細画面でもコメント数を表示する

## バリエーション

| バリエーション | 内容 |
|---|---|
| コメントなし | 「まだコメントはありません」と表示 |
| コメントが多数 | 「もっと見る」ボタン方式で対応 |

---

## エラーケース

| ケース | 発生条件 | ユーザーへの表示 |
|---|---|---|
| テキスト未入力 | コメントが空白のみ | 「コメントを入力してください」 |
| 文字数超過 | テキストが 281 文字以上 | 「280 文字以内で入力してください（現在 {n} 文字）」 |
| 他ユーザーのコメントの削除 | コメントの user_id がログインユーザーと不一致 | HTTP 403 エラー（削除ボタン自体を非表示） |
| 未ログインでコメント投稿 | 認証トークンがない | ログイン画面へリダイレクト |
| API エラー | サーバーエラーや通信障害 | 「コメントの送信に失敗しました。再度お試しください」 |
