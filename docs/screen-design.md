# Hitokuchi 画面設計書

関連ドキュメント：[機能一覧](./features.md) | [要件定義](./requirements.md)

---

## 概要

Hitokuchi の画面一覧とワイヤーフレーム、および画面遷移図を定義します。フロントエンドは React 19 + TypeScript + MUI を使用し、レスポンシブデザインで PC・スマートフォンの両方に対応します。

---

## 画面一覧

| 画面ID | 画面名 | URL | 認証要否 |
|---|---|---|---|
| S-01 | ログイン画面 | `/login` | 不要 |
| S-02 | 新規登録画面 | `/register` | 不要 |
| S-03 | タイムライン画面 | `/` | 任意（全体タブは不要、フォロー中タブは必要） |
| S-04 | 投稿詳細画面 | `/posts/:id` | 不要 |
| S-05 | 投稿作成画面 | `/posts/new` | 必要 |
| S-06 | 投稿編集画面 | `/posts/:id/edit` | 必要（自分の投稿のみ） |
| S-07 | プロフィール画面 | `/users/:username` | 不要（編集・フォローは必要） |
| S-08 | ユーザー検索画面 | `/search` | 不要 |
| S-09 | フォロー中一覧画面 | `/users/:username/following` | 不要 |
| S-10 | フォロワー一覧画面 | `/users/:username/followers` | 不要 |

## 各画面の詳細

### 1. ログイン画面（S-01）

**目的：** メールアドレスとパスワードでログインする

```
┌──────────────────────────────────────┐
│                                      │
│           Hitokuchi                  │
│                                      │
│  メールアドレス                      │
│  ┌──────────────────────────────┐    │
│  │                              │    │
│  └──────────────────────────────┘    │
│                                      │
│  パスワード                          │
│  ┌──────────────────────────────┐    │
│  │                              │    │
│  └──────────────────────────────┘    │
│                                      │
│       ┌──────────────────┐           │
│       │    ログイン      │           │
│       └──────────────────┘           │
│                                      │
│  アカウントをお持ちでない方は        │

│                                      │

```

## 画面遷移図

```
[未ログイン状態]

  ┌────────────┐   登録成功    ┌──────────────────┐
  │ 新規登録   │ ──────────→  │                  │
  │ (S-02)     │              │  タイムライン     │
  └────────────┘              │  (S-03)          │
       ↑                      │                  │
  リンク                       └──────────────────┘
       │                             ↑  ↑  ↑
  ┌────────────┐   ログイン成功       │  │  │
  │  ログイン  │ ────────────────────┘  │  │
  │ (S-01)     │                        │  │
  └────────────┘                        │  │
       ↑                                │  │
  未認証リダイレクト（投稿作成・フォロー等）  │

[ログイン後の遷移]

  タイムライン (S-03)
    │
    ├── 投稿カードクリック ────────→ 投稿詳細 (S-04)
    │                                    │
    ├── ユーザー名クリック ──→ プロフィール (S-07)
    │
    ├── + 投稿するボタン ────────→ 投稿作成 (S-05)
    │
    └── 検索アイコン ────────────→ ユーザー検索 (S-08)
                                        │
                                        └── 結果クリック → プロフィール (S-07)

  投稿詳細 (S-04)
    │
    ├── 編集ボタン（自分の投稿）── → 投稿編集 (S-06)
    │
    └── ユーザー名クリック ──────→ プロフィール (S-07)

  プロフィール (S-07)
    │
    ├── フォロー中 数字クリック ──→ フォロー中一覧 (S-09)
    │                                    │
    └── フォロワー 数字クリック ──→ フォロワー一覧 (S-10)
                                         │
                                   ユーザー名クリック
                                         │
                                         ↓
                                  プロフィール (S-07)
```
